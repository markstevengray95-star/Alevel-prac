DATA & CPAC TOOLKIT

Analysis tools built into every practical

Uncertainty

Use instrument resolution and repeat spread to estimate absolute and percentage uncertainty.

% uncertainty = Δx / x × 100

Graphing

Plot processed data, inspect the best-fit gradient and use a large triangle when interpreting experimental graphs.

gradient = Δy / Δx

Repeat readings

Take multiple measurements, identify anomalies and compare mean values instead of relying on one reading.

mean = Σx / n

Evaluation

Link each limitation to a specific effect on the result, then propose a realistic improvement.

limitation → effect → improvement
